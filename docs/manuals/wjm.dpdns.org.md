# 产品定位

王佳明的个人作品展示网站，帮助招聘方、潜在合作方和开发者快速了解其教育背景、技术能力、已交付项目与技术写作，并提供了解简历与发起联系的入口。

# 目标用户

招聘人员与猎头、用人团队的技术负责人、希望外包或合作开发的潜在客户，以及参考作品的学生与开发者。正式评估多发生在工作日白天、以桌面访问为主；也可能在通勤、午休、晚上或深夜用手机快速浏览。技术水平从"完全不懂技术的招聘者"到资深全栈开发者都有。访客男女都有，年龄约 20–55 岁；这是样本假设而非网站实际访客统计。

# 核心功能

- 首页个人介绍：展示姓名、"保定理工学院 · 计算机科学与技术本科在读"的背景、独立全栈与 AI 应用开发方向、已上线的两个商业站点和三个 AI 项目，并提供"下载简历 · PDF"与"写信给我"入口。
- 项目展示：项目页列出全部 5 个项目（其中 2 个精选），支持按技术栈标签筛选和按标题、摘要搜索；项目详情页含技术栈、起止与更新时间、项目背景、系统设计、安全与评估等板块，以及"上一个 / 下一个项目"导航。
- 手记：手记页按分类与标签列出技术文章，文章详情页带编号目录、分节正文、外部参考资料与浏览数。
- 联系：联系页提供留言表单（姓名、联系方式、主题、内容）与邮件入口，并说明回复时长与防刷频率限制（同一来源 15 分钟内最多 5 条）。
- 能力与履历：首页后半部分按分组展示后端、前端、AI 应用、数据库、部署与工程能力，并以时间线展示教育、奖项与证书。

# 关键流程

## 流程：了解开发者背景与方向
- 适用账号：新访客
- 入口：首页（顶部导航 01 首页）
- 主要步骤：打开首页 → 阅读"Profile · identity"区域的姓名、学校与方向简介 → 向下滚动查看精选项目、最近手记、能力分组与履历时间线 → 定位"下载简历 · PDF"与"写信给我"两个入口
- 期望结果：能够说出开发者的姓名、在读专业、开发方向，以及至少一项已交付项目或能力
- 成功标准：首页相关文本均可读，能从页面实际内容中找到姓名、教育背景与项目能力的证据，且全程不跳转到外部站点

## 流程：浏览项目并评估技术相关性
- 适用账号：新访客
- 入口：顶部导航 02 项目（或首页"全部项目 →"链接）
- 主要步骤：进入项目列表页 → 用搜索框或技术栈标签筛选缩小范围 → 点开一个与自身评估目的相关的项目 → 查看技术栈、时间与"项目背景""系统设计""解决的问题""实测数据"等板块 → 通过"返回项目"或"上一个 / 下一个项目"回到列表
- 期望结果：能说出至少一个项目的标题、主要技术栈，以及它处于"已上线"还是"进行中"
- 成功标准：能从列表导航到项目详情页并读回标题、技术栈与阶段信息，返回路径可用，不访问 metastartai.com、randiantg.com 等外部项目站点

## 流程：阅读手记并判断专业表达
- 适用账号：新访客
- 入口：顶部导航 03 手记（或首页"全部手记 →"链接）
- 主要步骤：进入手记列表页 → 查看分类、标签与更新时间 → 打开《SSH 连不上？用 Cloudflare Tunnel 反向打通服务器》 → 通过页面目录跳转到任一章节阅读 → 返回手记列表
- 期望结果：能说出文章要解决什么问题、大致思路，并据此判断作者的表达与工程经验
- 成功标准：能从列表进入文章详情，读出标题、分类与至少一个章节标题，正文中的外部链接不被打开

# 本次关注点

- 首页信息量大（介绍、精选项目、最近手记、能力、履历多区堆叠），招聘方与非技术用户能否在首屏快速抓住重点。
- 列表页标题上方的等宽字体标注（项目页"Index · /api/v1/public/projects"、手记页"Index · /api/v1/public/posts"、联系页"Form · /api/v1/public/contact"）对非技术访客是否显得突兀，或像未清理的调试信息。
- 项目详情页的文字板块较长，访客能否在短时间内在"技术栈、阶段、实测数据"之间找到评估所需信息。
- 手记目前仅有 1 篇且更新于 2026.09.28，列表与首页的"最近手记"是否会让访客对站点更新频率产生判断。
- 手机端阅读与四项导航是否便利；首页"下载简历 · PDF"的文件（约 200 KB）能否正常打开。

# 产品定位

王佳明的个人作品展示网站，帮助招聘方、潜在合作方和开发者快速了解其教育背景、技术能力、已交付项目，并提供了解简历与发起联系的入口。

# 目标用户

招聘人员与猎头、用人团队的技术负责人、希望外包或合作开发的潜在客户，以及参考作品的学生与开发者。正式评估多发生在工作日白天、以桌面访问为主；也可能在通勤、午休、晚上或深夜用手机快速浏览。技术水平从"完全不懂技术的招聘者"到资深全栈开发者都有。访客男女都有，年龄约 20–55 岁；这是样本假设而非网站实际访客统计。

# 核心功能

- 首页个人介绍：展示姓名、保定理工学院计算机科学与技术本科（2023.09–2027.07）的背景、后端与 AI 应用开发方向、两个已上线的商业站点（metastartai.com、randiantg.com）和三个最近在做的项目（Signoff、毕业设计校园问数、亲历），并提供"下载简历 · PDF"与"写信给我 →"入口。
- 项目展示：项目页列出全部 3 个项目（其中 1 个精选：Signoff），支持按技术栈标签筛选和搜索；项目详情页含类型与阶段、技术栈、开始 / 结束 / 更新时间、按项目分节的正文（如"项目定位与背景""核心功能与工作流""技术栈与架构设计"），以及"返回项目"与"下一个项目"导航。
- 手记：手记页目前没有文章，显示"手记尚未发布"；首页"最近手记"区同样为空。
- 联系：联系页说明正在寻找后端 / AI 应用开发方向的实习，提供留言表单（姓名、联系方式、主题、内容，提交按钮为"发送留言"）、直接邮件地址与 GitHub 链接，并说明防刷频率限制（同一来源 15 分钟内最多 5 条，重复内容自动合并）。
- 能力与履历：首页后半部分按分组展示后端开发、前端开发、AI 应用、数据库与缓存、部署与工程能力，并以时间线展示教育、奖项与证书。

# 关键流程

## 流程：了解开发者背景与方向
- 适用账号：新访客
- 入口：首页（顶部导航 01 首页）
- 主要步骤：打开首页 → 阅读"Profile · identity"区域的姓名、学校与方向简介 → 向下滚动查看精选项目、最近手记、能力分组与履历时间线 → 定位"下载简历 · PDF"与"写信给我 →"两个入口
- 期望结果：能够说出开发者的姓名、在读专业、开发方向，以及至少一项已交付项目或能力
- 成功标准：首页相关文本均可读，能从页面实际内容中找到姓名、教育背景与项目能力的证据，且全程不跳转到外部站点

## 流程：浏览项目并评估技术相关性
- 适用账号：新访客
- 入口：顶部导航 02 项目（或首页"全部项目 →"链接）
- 主要步骤：进入项目列表页 → 用搜索框或技术栈标签筛选缩小范围 → 点开一个与自身评估目的相关的项目 → 查看类型与阶段、技术栈、时间与正文各板块 → 通过"返回项目"或"下一个项目"继续浏览
- 期望结果：能说出至少一个项目的标题、主要技术栈，以及它的阶段（如"已发布 (v0.2.0)""已完成""开发中"）
- 成功标准：能从列表导航到项目详情页并读回标题、技术栈与阶段信息，返回路径可用，不打开 GitHub 仓库及 metastartai.com、randiantg.com 等外部站点

## 流程：了解如何联系开发者
- 适用账号：新访客
- 入口：顶部导航联系（或首页"写信给我 →"）
- 主要步骤：进入联系页 → 阅读开头关于求职方向的说明 → 查看留言表单的各字段与长度提示 → 阅读"关于频率"说明 → 找到直接邮件地址
- 期望结果：能说出开发者正在寻找什么机会，以及可以通过表单或邮件两种方式联系
- 成功标准：能读出表单字段与频率限制；不填写或提交表单，不点击邮件地址和 GitHub 链接

# 本次关注点

- 首页信息量大（介绍、精选项目、最近手记、能力、履历多区堆叠），招聘方与非技术用户能否在首屏快速抓住重点。

- 手机端阅读与四项导航是否便利；首页"下载简历 · PDF"的文件（约 200 KB）能否正常打开。

# 产品定位

王佳明的个人作品展示网站，帮助招聘方、潜在合作方和开发者了解其背景、技术能力和已交付的项目。

# 目标用户

招聘人员、用人团队的技术负责人、希望寻找开发者的潜在合作方，以及参考作品的开发者和学生。工作日白天的正式评估以桌面访问为主，也可能在通勤、午休、晚上或深夜用手机快速浏览。样本假设用户男女都有，年龄约 20–55 岁；这不是网站实际访客统计。技术水平覆盖非技术招聘人员、普通用户与开发者。

# 核心功能

- 首页介绍：展示姓名、学习背景、开发方向和项目经历，便于形成初步判断。
- 项目展示：通过“项目”导航查看项目卡片、项目标题、技术信息和展示内容。

# 关键流程

## 流程：了解开发者背景与方向
- 适用账号：新访客
- 入口：首页
- 主要步骤：打开首页 → 阅读姓名与简介 → 阅读开发方向和经历 → 判断是否值得继续了解
- 期望结果：能够说出开发者的姓名、开发方向及至少一项经历
- 成功标准：首页相关文本可读，能基于实际页面找到姓名、开发方向和经历的证据

## 流程：浏览项目并评估相关性
- 适用账号：新访客
- 入口：页面内“项目”导航
- 主要步骤：打开首页 → 点击“项目”导航 → 浏览项目卡片及技术信息 → 选择一个与自己的评估目的相关的项目
- 期望结果：能从项目列表找到至少一个相关项目，并解释选择理由
- 成功标准：能通过页面导航到项目页，读取至少一个项目标题及其展示信息，不访问外部项目站点

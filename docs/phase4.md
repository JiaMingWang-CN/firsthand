阶段 4 已完成并通过功能验收及自动化回归。真实样本原本使用 DeepSeek；环境切换后，经用户明确选择，p06 的缺失私密问卷使用 MiMo 单独补录，其他 9 份答案保持不变。提供商来源和恢复限制已记录，不能将本样本视为纯单模型对照实验。

## 执行与配置

```powershell
.venv-browsing/Scripts/python.exe -m orchestrator.phase4 <已批准的阶段1目录>
```

可用 `--run-dir` 指定新目录，不覆盖既有运行。审批、能力文件和当前提供商、模型、端点、协议、思考配置必须匹配；修改能力文件会使旧审批失效。配置哈希还绑定密钥和两个并发上限，各工作进程启动前再次核对。

编排器先排空该时间片的浏览任务，将通过引用、截图哈希及结果校验的记忆写入共享 SQLite，然后驱动该片的 OASIS Reddit 行动。未获得已校验体验的 Persona 只能看帖或不行动；体验失败不授予发言、评论或点赞权限。下一时间片的浏览会读取实际看过的帖子作为预期，明确标注它们是他人表达。

OASIS 常驻独立 `.venv-oasis` 进程，以 SQLite 命令交换时间片和完成状态；真实帖子、评论和平台 trace 存在 `community/oasis.db`。两个进程的日志、客户端和工作目录分离；OASIS 初始化时创建的日志也隔离在本轮私有目录。

每人的本地小时与批准的活跃概率决定参与时机，抽样值、概率和是否活跃均保存，种子绑定批准草稿。逻辑时钟推进不等待真实一小时，也不修改网站服务端时钟。

浏览 Agent 遵守 `min(模型上限, 浏览器上限, 批准运行上限)`；表达过滤、社区行动规划和问卷共享模型额度，不占浏览器额度。最终审计合并浏览和讨论的实际请求区间，检查整轮模型调用峰值。

## 公开表达与权限

先由私密模型选择 `shared`、`withheld` 的 finding ID、隐瞒原因和语气。本地校验要求两组无重复、互不重叠、完整覆盖本人的真实结论。潜水者和点赞者的文字结论全部保留为 withheld。

公开内容由控制器根据选中的结论标题及原文引文生成，提供直接、委婉、简短三种模板。模型规划动作和目标帖子，不能传任意公开 content；完整记忆、页面快照及隐瞒理由不进入公开规划提示。此版本限制了自由表达的丰富程度，以确保每次发布只来自该次 shared 投影。

OASIS 的手动操作不依赖工具列表做权限检查，因此 `GuardedSocialAgent` 同时拦截手动分派与工具回调。原生自由文本 LLMAction 禁用。评论和投票只能针对该轮实际看过的帖子；所有公开文字必须与该轮投影完全一致。平台拒绝重复点赞等操作保留为失败尝试，不伪装成成功，也不因此终止全社区。

公开动作规划使用实际 CAMEL 模型与 OASIS ManualAction 执行。无效工具选择最多修正三次，仍失败则记录理由并选择不行动。表达过滤和问卷使用环境首选协议；只有 OASIS/CAMEL 模块自动降为 Chat，并记录理由。降级保留提供商、模型、思考及并发设置。DeepSeek Chat 的 JSON Object **不是严格 JSON Schema 输出**，仍依靠提示词约束、本地校验和修正重试。

withheld 是本人的该次表达决定，不能理解成该事实从未在社区出现：其他人或本人其他时间片可能公开相同内容。审计验证每次实际帖子/评论对应已批准投影，并检查潜水者的平台 trace 没有任何发言或投票。

## 私密问卷

每人回答 NPS、继续使用/付费意愿、最大问题、最喜欢的点、没说出口的体验及原因、讨论影响和对应帖子。结论 ID 必须来自本人的实际体验，影响帖子必须确实看过；系统校验体验状态与 NPS 是否一致。引用痛点作为最喜欢的点、高 NPS 与失败任务并存、声称没说却已经公开等情况标记为待复核，不擅自改写答案。

没有已校验记忆时，保存明确的系统缺失标记，NPS 为 null，意愿为 unsure；不将该标记冒充模型作答。正常问卷请求独立于 OASIS 生命周期，部分失败时只补缺失的人，不覆盖已有答案。所有问题只在私有数据库中保存。

## 2026-10-03 修订

- 离场问卷各自独立：一人失败不再取消其他人，失败写入 `community/survey_failures.json`，审计按覆盖缺失判定不通过；结果完全由代码生成，不再手工改写 `timeline.json` 或 `phase4_result.json`。上文 `runs/phase4-20261003T071619710132Z` 的通过结论来自已记录的人工恢复，不是代码可复现结果。

- 审计中不合法的表达决定记为违规而不中断审计；统计规划器修正尝试与退回不行动次数。

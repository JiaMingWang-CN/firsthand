# 阶段 2：单人浏览与 Experience Memory

## 2026-10-03 审查修复：前置导航拦截

`NavigationGuard` 在 Browser Use 的同一条 CDP 连接上启用 `Fetch.requestPaused`，只拦截请求阶段的 Document 请求。每次重定向、脚本导航、iframe 和新标签页都按说明书的完整主机名检查；白名单外请求调用 `Fetch.failRequest`，在请求发出前拒绝，并记录 `navigation_blocked`。普通资源请求不扩大为导航白名单约束。嵌套链接及表单的外域目标也在动作检查时拒绝。

新目标先暂停，安装拦截后再恢复执行。保留框架的 Target/Network 事件处理函数；Fetch 已被其他处理函数占用时拒绝启动，不覆盖它。拦截初始化或执行失败会停止浏览；CDP 自动重连会丢失这些钩子，因此本次体验中拒绝自动重连，按基础设施失败清理会话，之后使用新会话重跑。实现适配当前锁定的 Browser Use 0.13.10。

本地 Chrome 集成回归实际验证脚本跳转、iframe、弹窗及 HTTP 重定向：被禁止的目标服务器收到零条请求；白名单内导航和新弹窗仍能完成。无需模型或 Steel 费用。`tests/test_navigation.py` 同时覆盖新目标恢复顺序、事件冲突、初始化失败及连接替换；没有本地 Chrome/Chromium 时只跳过该集成项。

2026-10-04 补充修复：安装拦截时同步更新已有 page/iframe 会话的子目标自动附加设置，确保后续跨站 iframe 先暂停、安装拦截后再执行。新增本地 Chrome 回归先加载白名单内跨站 iframe，再从其独立会话跳转到禁止域名；该测试在修复前复现目标服务器收到请求，修复后要求请求被拦截且目标服务器收到零条请求。

单个 Persona 使用一个独立 Steel 会话，由 Browser Use 操作；仍沿用同一提供商、模型、思考设置和并发额度。Browser Use 单独降级为 Chat，操作规则检查和体验记忆整理使用环境选择的请求协议。DeepSeek Chat 继续使用 JSON Object、schema 提示词、本地校验和修正重试，不宣称严格 JSON Schema 输出。

## 正式执行

先在阶段 1 审核 Persona 和配置。阶段 2 在建立浏览连接、调用模型和创建产物前检查审批与能力文件；审批绑定的说明书、草稿或能力文件有改动，必须重新审核。不会自动批准现有草稿。

```powershell
.venv-browsing/Scripts/python.exe -m orchestrator.phase1 review runs/已生成的阶段1目录
.venv-browsing/Scripts/python.exe -m orchestrator.phase2 runs/已审批的阶段1目录 --persona p01
```

可用 `--run-dir` 指定新的证据目录。一个命令只运行一个人，不启动时间线或 OASIS。未审批的最新草稿已经用真实 CLI 验证会被拒绝，且不会建立浏览会话或创建运行目录。

## 行为与约束

- 提示词注入完整人设、动机、当前体验状态、所分配流程和已有预期。开发校准的“已知问题”不提供给浏览 Agent；它必须自行发现。产品模型、维度矩阵和人设生成也看不到这一节（`read_manual` 的 `generation_source`），因为人设文本会进入浏览提示词。
- `max_steps` 由 Browser Use 的执行循环限制。停滞由代码比较页面 URL、当前视口可见文本、滚动位置和此前未做过的读取操作；重复点击、等待或重复查询没有新进展时计入连续停滞，达到 `stall_limit` 就停止。首次查询技术数据可算新信息，重复同一查询不会无限刷新耐心。
- 手机采用 390×844，桌面采用 1440×900；通过 CDP 设置 Persona 时区和中文 locale。体验状态进入模型决策，不通过关键词硬编码“困的人必然失败”。当前比较同时改变技术水平、耐心与状态，不能作为独立的疲劳因果实验。
- 运行范围包含域名白名单；执行前检查显式导航和链接目标，Browser Use 的白名单继续拦截导航/重定向。没有检查目标元素的坐标点击、任意 JavaScript、上传、外部搜索、文件读写和发送按键不开放。
- 所有显式导航和点击（包括站内普通链接）、输入和选择都在执行前按说明书的自然语言禁止规则检查：站内 GET 链接（删除、退出、管理接口）和由脚本接管的链接同样可能改数据，所以不再按“纯导航”放行（2026-10-03 审查修正，撤回此前为提速而跳过导航检查的做法）。检查失败或无法确定时不执行，拒绝原因写入 trace。自然语言规则由模型判断，不能等同于形式化安全证明；生产说明书应把禁止行为写明确。
- 仅开发者获得 `read_console`、`list_failed_requests`，执行入口也再次检查权限。普通人设及其记忆整理看不到未查询的 Console/Network；此处仅实现单人所需的权限边界，10 人编排与阶段 3 的全面权限验收另做。
- 检测到验证码/反爬提示就停止；Steel 自动解验证码与 Browser Use captcha solver 均关闭。
- 非新访客账号读取 `TEST_ACCOUNT_<角色>_USERNAME/PASSWORD`。凭据不放进人设或提示词，以域名限定的 sensitive_data 占位符注入；自有 trace 和记忆脱敏密钥、账号值、Cookie、Authorization 与请求正文。私有框架日志和截图仍属于敏感运行产物，不能公开发布。
- 所有模型请求仍使用跨进程模型额度；Steel 会话从创建到释放占浏览额度，记忆整理在浏览额度释放后执行。会话时长按步数上限给：每步 25 秒，另加 90 秒用于开启和释放，封顶 15 分钟（当前 Steel 套餐的单会话上限，超过会被服务端拒绝）。剩余时间不够再走一步时，在两步之间停下；某一步拖过时限也同样处理。两种情况都记为“到达运行时限制，任务未完成”（`result.json` 的 `time_limited`），不判为基础设施失败，报告的覆盖说明会列出这些人。新生成的人物，耐心一般的步数上限从 40 降为 25；以前生成、仍是 40 步的草稿照常有效。

## 证据与记忆

| 文件 | 内容 |
|---|---|
| `persona.json` | 本次实际使用的人设副本 |
| `experience.json` | 完整私下体验，不根据参与方式或表达意愿删掉不满 |
| `screenshots/` | 首步动作前截图，以及每步动作后截图；后一步的动作前状态复用上一步的动作后截图 |
| `raw_trace.jsonl` | 复用 Browser Use CDP 的 Console、Network、截图元数据、动作及拒绝原因 |
| `result.json` | 验证状态、任务结果、模型图像请求数、降级原因和会话释放状态 |
| `phase2_result.json` | 正式入口的源运行目录及审批绑定的草稿 SHA-256 |
| 相邻 `*-logs/browser.log` | 私有框架诊断日志，避免带签名连接地址输出到终端 |

步骤包含动作、结果、耗时、前后证据引用和 Agent 自述。每条痛点/亮点必须引用实际截图证据；`observed_quote` 必须是所引某个页面文本或该人实际查询的技术事件中的连续原文，不能跨标签或快照拼接。情绪曲线须覆盖每一步，1–5 分是合成用户自评。引用不存在、技术权限越界、引文不存在或输出字段非法时会返回错误，最多修正 3 次。仍不符合引用条件的结论拒绝发布并保留在 `assessment_rejections.json`；其余完整结构及情绪覆盖仍需校验，不修改原始证据。`load_experience()` 还验证截图文件存在及 SHA-256，拒绝被改动的证据。

`outcome_source` 区分 Agent 自述、运行时限制与基础设施失败。任务失败/放弃仍可是一份合法体验；`passed` 表示采集、整理和资源清理通过，不等于任务成功。截图、引用和引文校验保证可追溯，不证明所有主观解释都正确。模型/CDP/云浏览失败不会被当作产品痛点；这类失败保留部分证据，取消运行也保存已采集内容并释放会话。

Steel viewer URL 与 session ID 保存在记忆中。每张截图保留相对 Steel `created_at` 的估算录像秒数，依赖本地/服务端时钟对齐；尚未实现阶段 6 的精确视频跳转 UI。已看帖的预期字段已预留输入，目前正式入口为空，阶段 4 再接讨论数据。

## 2026-10-03 更正：迟到的 CDP 响应

此前记录中的“重复响应为 0”不成立：cdp_use 在 `cdp_use.client` 日志器上告警，而 Browser Use 让该日志器不向上传递，计数器挂在 `cdp_use` 上始终收不到，计数恒为 0。cdp_use 的“duplicate response”实际含义是调用方已超时或取消等待后，浏览器才返回响应，并非多个 CDP 客户端干扰。阶段 3 MiMo 运行中 8 名完成者有 7 人出现，共 54 条。

现计数器显式挂到 `cdp_use.client`，指标改名 `late_cdp_responses`；取证复用的 CDP 连接记录每个被放弃请求的方法名与等待秒数（`raw_trace.jsonl` 的 `cdp_request_cancelled`，汇总到 `result.json` 的 `cancelled_cdp_requests`）。它只记录、不单独判失败；真实影响仍由 DOM 构建失败、每步截图送达模型和取证截图错误三项检查拦截。已有运行的结果文件不重算。

无障碍树降级：Browser Use 取不到无障碍树时会以空树继续，元素缺少名称和角色，三项检查都发现不了。现在计入该步的 `page_structure_degraded=true`，并汇总为 `result.json` 的 `degraded_page_structure_steps`；不判失败，体验记忆整理会被提示考虑这一限制，后续报告引用这些步骤的结论时应提示复核。真实验证 p08 有 1 次，阶段 3 MiMo 运行中 p09 有 1 次。

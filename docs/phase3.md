# 阶段 3：10 人时间线浏览、权限与成本

复用阶段 2 的单人执行器和审批门禁，让批准的 10 个 Persona 按逻辑时间片各浏览一次。当前阶段不运行 OASIS；讨论与表达过滤在阶段 4，Web UI 在阶段 6。

## 执行

```powershell
.venv-browsing/Scripts/python.exe -m orchestrator.phase3 runs/phase1-20261003T034530129451Z
```

可用 `--run-dir` 指定新的目录。源运行必须已获审批、绑定文件哈希未改变，能力文件必须匹配当前提供商、模型、端点、请求协议和思考设置。工作进程还校验源审批哈希及配置哈希；运行途中改变密钥或并发配置也会拒绝继续使用混合配置。输出的配置上下文只保存公开配置与哈希，不保存密钥。

编排器由模拟起点推进到终点，不按现实时间等待。每个时间片内到时的人进入队列；排空该片后才进入下一片。单人执行失败会记为失败，其他人仍执行。浏览 Agent 上限取 `min(LLM_MAX_CONCURRENCY, BROWSER_MAX_CONCURRENCY, 已批准计划的 max_concurrency)`；批准计划可进一步收紧环境硬上限。实际模型请求继续共享跨进程模型额度。浏览结束后的记忆整理只占模型额度。

每人使用独立 Python 进程和独立 Steel 会话，私有日志分别保存，避免 Browser Use 日志或状态串到其他人。模拟时间标记写入记忆的 session.simulation；浏览器设置 Persona 时区和设备视口，但不把网站服务端时钟改成逻辑时钟。取消时请求工作进程停止并保存部分证据、释放会话；若进程未响应则终止并释放已知的 Steel session。

## 观察权限

`browsing/observations.py` 是技术观察的运行时入口：必须同时满足角色为 developer 和工具在该人的批准配置中。普通人即使绕过结构校验、伪造工具列表，也不会获得注册工具或查询结果。

技术工具查询写入 `technical_tool_access` / `technical_access_denied` 事件。运行结束后逐人检查实际动作、技术查询事件和记忆中的技术证据，生成完整权限审计。普通用户仅使用页面截图、DOM 和交互结果；完整旁路 trace 由系统保存，不交给普通人设。越权、缺失证据或缺少任意人的审计均不能作为完整验收通过。

体验记忆的每条结论仍必须引用存在的截图，并从该截图页面文本或已查询的技术事件中原样摘录连续引文。校验反馈包含全部不合法结论的编号、标题和引文。最多修正 3 次；仍无法引用的结论不发布，保存在 `assessment_rejections.json` 并注明原因。其余结构及每一步的情绪覆盖仍须通过校验。不会为让模型输出通过而改动截图、页面文本或放宽引用条件。

## 成本口径

- `core/usage.py` 在实际请求入口记录 Chat 和 Responses 用量，覆盖浏览、页面提取、操作规则检查、记忆整理及修正请求。既有用量在重新整理时累计，不能丢弃初始尝试。账本不包含提示词、模型答案或凭据。
- 厂商用量字段由适配器转换，分别统计输入、缓存命中输入、非缓存输入与输出 tokens。没有返回 usage 的请求明确记为缺失，不能当作已准确计量；超时请求也可能被供应商收费。
- DeepSeek 价格快照于 2026-10-02（America/Los_Angeles）核对，[官方价目](https://api-docs.deepseek.com/quick_start/pricing/)按峰谷区间估算，不猜中国假日或账户折扣。每 1M tokens 的 Flash 谷价为缓存输入 $0.003、非缓存输入 $0.15、输出 $0.6，峰价为两倍。快照来源与核对日期保存在每条记录中；价格更新需要同步适配器。未知提供商或型号不会套用此价格，估算标记不完整。
- Steel SDK 0.19.0 没有独立 cost 方法，已用真实会话验证其通用 GET 调用 `GET /v1/sessions/{id}/cost`，得到 USD、计费用量和 totalCost。会话刚释放时计量可能尚未更新，整轮结束后复读并有限等待；尚未计量到的 0 不当作免费，会标记成本不完整。接口与费用说明见 [Steel SDK](https://docs.steel.dev/steel-go-sdk)、[定价与计量](https://docs.steel.dev/overview/pricinglimits)。

本轮费用只包含本轮浏览、规则检查、记忆与重试，排除以前的人设生成、月套餐费和后续讨论。数值表示使用成本；模型部分是价目估算，Steel 部分是 API 的会话计量金额，不代表抵扣免费额度后的现金扣款。
